간단하고 재미있게 – 집에서 트렌드를 맛보세요!
#

버블티와 아시아풍 간식의 즐거움을 집 주방으로 가져올 수 있도록 엄선된 레시피를 탐험해보세요. 각 레시피는 BOBA CHiC 키트와 재료를 사용하여 진정한 맛과 식감을 간편하고 즐겁게 구현하도록 제작되었습니다.

타피오카 큐브 달콤한 풀 젤리 수프
#

부드러운 풀 젤리와 쫄깃한 타피오카 큐브가 어우러진 상쾌한 간식.

재료:

  • 달콤한 풀 젤리 수프 w/ 타피오카 큐브 키트

만드는 법:

  1. 젤리 가루를 끓는 물에 섞습니다.
  2. 완전히 녹을 때까지 잘 저어줍니다.
  3. 타피오카 큐브를 넣습니다.
  4. 원한다면 꿀이나 우유를 뿌려도 좋습니다.

영상

팝 캐비어 라면
#

한 입에 터지는 강렬하고 고소한 맛, 팝핑 보바와 함께.

재료:

  • BOBA CHiC 팝 캐비어 라면
  • 선택 토핑: 파, 김, 계란

만드는 법:

  1. 끓는 물에 면을 4~5분간 삶습니다.
  2. 물을 빼고 그릇에 옮깁니다.
  3. 동봉된 소스 팩을 넣습니다.
  4. 골고루 섞어 코팅합니다.
  5. 계란 프라이, 파, 원하는 토핑을 올립니다.
  6. 팝핑 보바 팩의 물을 빼냅니다.
  7. 팝핑 보바(매운맛 또는 토마토 맛)를 넣습니다.
  8. 다시 섞어 맛있게 즐기세요!

영상

즉석 팝핑 보바 칵테일
#

파티 필수품—재미있고 톡 쏘며 잊지 못할 맛.

재료:

  • BOBA CHiC 팝핑 보바 칵테일 키트
  • 얼음 팩
  • 선택 가니시

만드는 법:

  1. 얼음 팩을 열고 과일 차 가루를 넣습니다.
  2. 스프라이트 또는 탄산수를 붓습니다.
  3. 가루가 녹을 때까지 저어줍니다.
  4. 칵테일/모크테일 팝핑 보바를 넣습니다.
  5. 빨대를 꽂고 톡톡 터지는 즐거움을 맛보세요!

영상

블랙 가바 라이스 말차 아마자케 탕위안
#

건강과 전통이 어우러진 포근하고 독특한 퓨전.

재료:

  • BOBA CHiC 블랙 가바 라이스 말차 아마자케 라떼
  • 탕위안 (구입 또는 직접 만든 쌀떡)

만드는 법:

  1. 탕위안을 삶아 떠오를 때까지 익힙니다.
  2. 뜨거운 물에 블랙 가바 라이스 말차 아마자케 가루를 녹입니다.
  3. 익힌 탕위안을 말차 아마자케 수프에 넣습니다.
  4. 원하면 설탕으로 단맛을 조절하세요.

영상

보바 티 에그 타르트
#

동서양의 만남, 달콤하고 크리미하며 쫄깃한 간식.

재료:

  • BOBA CHiC 휘핑 폼 버블 티 키트
  • BOBA CHiC 버블 티 키트
  • 계란 2개
  • 설탕 20g
  • 타르트 껍질

만드는 법:

  1. 밀크티, 계란, 설탕을 섞습니다.
  2. 혼합물을 타르트 껍질에 80% 정도 채웁니다.
  3. 160°C(320°F)에서 15분간 굽습니다.
  4. 휘핑 폼 가루를 준비합니다.
  5. BOBA CHiC 즉석 보바를 20~30초 전자레인지에 돌립니다.
  6. 타르트 위에 휘핑 폼을 올립니다.
  7. 데운 흑설탕 타피오카 보바를 뿌립니다.

영상

과일 팝핑 보바 샐러드
#

다채롭고 상큼하며 부담 없는 맛.

재료:

  • BOBA CHiC 아이스 팝핑 보바 과일 차 키트
  • 제철 채소와 과일 (망고, 키위, 베리 등)
  • 오리지널 요거트

만드는 법:

  1. 과일 가루를 요거트에 섞습니다.
  2. 부드럽게 될 때까지 저어줍니다.
  3. 샐러드 채소와 과일을 그릇에 담습니다.
  4. 팝핑 보바를 올려 즙이 터지는 식감을 더합니다.
  5. 과일 요거트를 샐러드 위에 뿌립니다.
  6. 섞어 차갑게 즐기세요.
